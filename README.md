## Useless app made for TG 2025

Plain web app with html, css and js.
Presents the TG logo and a slider which can adjust filter: brightness on the logo.
Also button that starts audio-listening via microphone and adjusts slider according to volume.

* Installation:
    No installation needed. Just open index.html in web browser

* Requirements: 
    For volume sensor to work, browser needs access to microphone
